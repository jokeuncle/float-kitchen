# Float Kitchen 0.1.0 · AI 后厨预览版

原生 macOS 悬浮小厨房，将本地 AI 客户端的读取、搜索、执行、测试、等待确认、失败、完成与闲置变成八种厨师动作。工位牌显示活动信息，「订单小票」查看最近六步，「看懂后厨」提供完整说明与演示。

- Apple 芯片 Mac，macOS 14 或更新；无第三方运行时。
- DMG 拖入 Applications；也可下载 ZIP。提供 SHA256SUMS.txt 校验。
- 当前是本地签名的预览版，未经过 Apple 公证。首次打开若被系统阻止，确认来源后按「隐私与安全性」提供的操作处理，不要关闭系统保护。
- 首次为演示模式；「真实活动」只读监听近期 Codex / Claude 本地日志。自定义客户端可追加本地 JSONL 事件。
- 97项核心回归、11项打包应用检查、独立解压检查通过。真实 Codex exec 已逐项对账读取、搜索、测试失败、修复、重测通过和本轮完成；Claude 本轮未实跑。
- 修复重复前景道具、纹理串格、运行中工位牌截断与图文对齐；姿势切换采用淡入淡出。隐藏、遮挡、休眠与减弱动态效果均有处理。

完整使用方法见仓库 README 和 docs/动作说明书.md。客户端日志格式、自定义脚本可能影响细分识别；本轮结束不等于任务质量验收。应用不上传活动数据。
