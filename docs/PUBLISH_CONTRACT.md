# Publication contract

User authorized an independent GitHub repository, downloadable Mac app, usage documentation, matching Harnessloom website integration, commits/pushes and public website publication.

Scope: Float Kitchen only. Keep Orbit source/history and existing products. Website changes are additive to the existing Harnessloom hub. Preserve production backend, data, commerce gates, TLS and downloads for other products. Lumen was an offline read-only sample source for omitted tools/commands; no Lumen dependency or data reader ships.

Accept:97 parser/tailer/classification checks; release signature and packaged view checks; real local codex exec with source event/state/text reconciliation; public source tag and release assets; exact download bytes/SHA256; desktop/mobile/light/dark website and guide controls; frontend-only immutable deployment with public hash checks and unchanged backend/gates.

Boundary: only dedicated app repository and necessary website/publication files. Existing unrelated website work is preserved; necessary already-live product hub source is included for a reproducible frontend. No purchase, user message, secret, credential, real conversation log or existing database is published.

Release:0.1.0 preview, macOS14+Apple Silicon, ad-hoc local signature, not Apple-notarized. Prior immutable website current is recorded by deployment tool. Rollback uses original deploy run/token and old frontend pointer, preserving backend/data. Abort publication on app/source reconciliation mismatch, failed artifact hash, website build/control-policy failure, missing download or broken product links.
